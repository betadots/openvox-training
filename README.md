# OpenVox Training

This repository contains a beginner-friendly training path for OpenVox and Puppet. The material is organized as a short agenda, a set of chapter notes, and sample solutions for selected exercises.

## What Is Here

- [05_agenda.md](05_agenda.md) outlines the three training days and the main topics covered.
- [10_puppet-infrastructure.md](10_puppet-infrastructure.md) introduces Puppet, facts, the agent workflow, and resources.
- [20_working-with-puppet.md](20_working-with-puppet.md) covers working with Puppet in practice.
- [30_git.md](30_git.md) gives a short Git introduction for the training exercises.
- [40_code-logic.md](40_code-logic.md) explains conditionals, lookup behavior, ordering, and iteration.
- [50_profiles.md](50_profiles.md) focuses on profile classes and more advanced module usage.
- [60_bolt.md](60_bolt.md) introduces Bolt and task execution.
- [solutions/](solutions/) contains sample solutions for selected exercises.
- [images/](images/) contains diagrams used throughout the training material.

## How To Use This Repo

Start with the agenda, then follow the chapter files in order. Each chapter is written as training material and some chapters include a practice section plus a link to a sample solution.

## Structure

The repository is intentionally lightweight so it can be referenced from documentation and issue fixes without extra setup. The Markdown files are the source of truth for the training content.
